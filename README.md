#  Jogo da Velha em Python com Pygame

<p align="center">
  <strong>Um clássico jogo da velha, reimaginado com uma interface gráfica interativa em Pygame</strong>
</p>

---

##  Sobre o Projeto

Este projeto consiste em um **Jogo da Velha** desenvolvido em Python utilizando a biblioteca **Pygame** para a criação da interface gráfica e interação com o usuário.

Foi desenvolvido como parte de um trabalho universitário da disciplina de **Programação de Computadores**, com o objetivo de aplicar conceitos fundamentais de lógica de programação, estruturas de controle, manipulação de eventos e desenvolvimento de interfaces gráficas.

Toda a implementação — desde a modelagem da lógica do jogo até a construção da interface e testes da aplicação — foi realizada exclusivamente por mim e por meu amigo.

---

##  Funcionalidades

-  Interface gráfica interativa desenvolvida com Pygame
-  Sistema de jogadas para dois jogadores
-  Verificação automática de vitória e empate
-  Atualização dinâmica do tabuleiro
-  Reinício da partida após o término do jogo
-  Experiência simples e intuitiva para o usuário

##  Objetivos do Projeto

Este projeto teve como principais objetivos:

- Desenvolver habilidades de resolução de problemas através da lógica de programação
- Aprender a utilizar a biblioteca Pygame para criação de interfaces gráficas
- Trabalhar o desenvolvimento de software em equipe
- Aplicar boas práticas de organização e estruturação de código

##  Aprendizados

Durante o desenvolvimento deste projeto, foram explorados diversos conceitos importantes, incluindo:

- Manipulação de eventos do teclado e mouse
- Pygame do zero
- Organização modular do código
- Controle de estados do jogo
- Desenvolvimento de interfaces gráficas com Pygame
